# Fluxo: API do Manager

> **Arquivo:** `manager.go`
> **Interface:** `TemplateManager`

## Fluxograma: GetTemplate

```mermaid
flowchart TD
    Start(["🟢 Manager.GetTemplate(name)"]) --> LockRL["🔒 mu.RLock()"]
    LockRL --> Lookup{"templates[name] existe?"}
    Lookup -->|✅ sim| ReturnTmpl["✅ retorna *template"]
    Lookup -->|❌ não| ReturnErr["❌ retorna nil, error\n'template not found'"]
    ReturnTmpl --> UnlockRL["🔓 mu.RUnlock()"]
    ReturnErr --> UnlockRL
    UnlockRL --> End(["🔵 FIM"])
```

flowchart TD

## Fluxograma: GetRequiredVariables

```mermaid
flowchart TD
    Start(["🟢 Manager.GetRequiredVariables(name)"]) --> GetTmpl["GetTemplate(name)"]
    GetTmpl --> GetErr{"sucesso?"}
    GetErr -->|❌ falha| ReturnErr["❌ retorna error (propagado)"]
    GetErr -->|✅ ok| GetRV["🔤 renderer.GetRequiredVariables(template)"]
    GetRV --> ForVar["🔁 Para cada var em template.RequiredVars"]
    ForVar --> AutoCheck{"isAutoGeneratedVar(var)?"}
    AutoCheck -->|✅ sim| SkipAuto["⏭️ ignora (ex: CURRENT_DATE)"]
    AutoCheck -->|❌ não| AddRequired["➕ append(var)"]
    SkipAuto --> ReturnFiltered["✅ retorna []string (auto-vars removidas)"]
    AddRequired --> ReturnFiltered
    ReturnErr --> End(["🔵 FIM"])
    ReturnFiltered --> End
```

## Fluxograma: loadFromSources (multi-fonte)

```mermaid
flowchart TD
    Start(["🟢 Manager.loadFromSources(sources)"]) --> LockW["🔒 mu.Lock()"]
    LockW --> ForSource["🔁 Para cada source em sources"]
    ForSource --> LoadTmpl["source.LoadTemplates()"]
    LoadTmpl --> LoadErr{"LoadTemplates\nsucesso?"}
    LoadErr -->|❌ falha| ContinueSource["⏭️ continue (tolerante a falhas)"]
    LoadErr -->|✅ ok| MergeTmpl["🔗 Para cada name, tmpl em templates:\n   m.templates[name] = tmpl\n   (última fonte vence)"]
    ContinueSource --> MoreSources{"mais sources?"}
    MergeTmpl --> MoreSources
    MoreSources -->|✅ sim| ForSource
    MoreSources -->|❌ não| UnlockW["🔓 mu.Unlock()"]
    UnlockW --> ReturnOK["✅ return nil"]
    ReturnOK --> End(["🔵 FIM"])
```

## Resumo de Locking

| Método | Lock Type | Propósito |
|--------|-----------|-----------|
| `GetTemplate` | `RLock` | Leitura única |
| `ListTemplates` | `RLock` | Leitura + cópia |
| `RenderTemplate` | `RLock` → `GetTemplate` | Leitura |
| `ValidateTemplate` | `RLock` → `GetTemplate` | Leitura |
| `GetRequiredVariables` | `RLock` → `GetTemplate` | Leitura |
| `GetTemplateNames` | `RLock` | Leitura |
| `HasTemplate` | `RLock` | Leitura |
| `loadFromSources` | `Lock` | Escrita (merge) |
