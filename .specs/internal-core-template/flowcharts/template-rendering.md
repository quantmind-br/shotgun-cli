# Fluxo: Renderização de Template

> **Funções:** `Manager.RenderTemplate()`, `Renderer.RenderTemplate()`
> **Arquivos:** `manager.go`, `renderer.go`

## Fluxograma: Manager.RenderTemplate

```mermaid
flowchart TD
    Start(["🟢 Manager.RenderTemplate(name, vars)"]) --> GetTemplate["🔍 Manager.GetTemplate(name)"]
    GetTemplate --> GetErr{"template\nencontrado?"}
    GetErr -->|❌ não| ReturnErr["❌ return '', error\n'template not found'"]
    GetErr -->|✅ sim| Render["📥 Renderer.RenderTemplate(template, vars)"]
    Render --> Return["✅ retorna string renderizada"]
    ReturnErr --> End(["🔵 FIM"])
    Return --> End
```

## Fluxograma: Renderer.RenderTemplate (pipeline principal)

```mermaid
flowchart TD
    Start(["🟢 Renderer.RenderTemplate(template, vars)"]) --> NilCheck{"template\n!= nil?"}
    NilCheck -->|❌ nil| ReturnNil["❌ return '', error 'template is nil'"]

    NilCheck -->|✅ ok| Validate["🔒 validateVariables(template, vars)"]
    Validate --> ValidateErr{"validação\nsucesso?"}
    ValidateErr -->|❌ falha| ReturnValidateErr["❌ return '', error\n'missing required variables' ou 'empty required variables'"]

    ValidateErr -->|✅ ok| Merge["🔀 mergeVariables(vars)"]

    Merge --> Step1["① Copia defaultVars → merged\n   (CURRENT_DATE = today)"]
    Step1 --> Step2["② Override por vars fornecidas"]
    Step2 --> Step3["③ Força CURRENT_DATE = time.Now().Format('2006-01-02')"]
    Step3 --> Substitute["🔄 substituteVariables(template.Content, merged)"]

    Substitute --> ForVar["🔁 Para cada (varName, value) em merged"]
    ForVar --> Sanitize["🧹 sanitizeVariableValue(value)\n   - CRLF→LF, CR→LF\n   - trim trailing spaces"]
    Sanitize --> Replace["🔗 strings.ReplaceAll(content,\n   '{'+varName+'}', sanitizedValue)"]
    Replace --> MoreVars{"mais vars?"}
    MoreVars -->|✅ sim| ForVar
    MoreVars -->|❌ não| ReturnRender["✅ retorna resultado final"]

    ReturnNil --> End(["🔵 FIM"])
    ReturnValidateErr --> End
    ReturnRender --> End
```

## Fluxograma: validateVariables

```mermaid
flowchart TD
    Start(["🟢 validateVariables(template, vars)"]) --> NilVars{"vars == nil?"}
    NilVars -->|✅ sim| InitVars["vars = make(map[string]string)"]
    NilVars -->|❌ não| MergeForVal["allVars = mergeVariables(vars)"]

    InitVars --> MergeForVal

    MergeForVal --> ForRequired["🔁 Para cada requiredVar em template.RequiredVars"]
    ForRequired --> AutoCheck{"isAutoGeneratedVar(requiredVar)?"}
    AutoCheck -->|✅ sim (ex: CURRENT_DATE)| SkipVar["⏭️ continue (ignora)"]
    AutoCheck -->|❌ não| GetValue["value, exists := allVars[requiredVar]"]

    GetValue --> Missing{"!exists?"}
    Missing -->|✅ sim| AddMissing["➕ missingVars = append(missingVars, requiredVar)"]
    Missing -->|❌ não| EmptyCheck{"trimmed value == ''?"}
    EmptyCheck -->|✅ sim| AddEmpty["➕ emptyVars = append(emptyVars, requiredVar)"]
    EmptyCheck -->|❌ não| SkipOk["⏭️ OK, continua"]

    AddMissing --> SkipOk
    AddEmpty --> SkipOk
    SkipVar --> SkipOk
    SkipOk --> MoreRequired{"mais requiredVars?"}
    MoreRequired -->|✅ sim| ForRequired
    MoreRequired -->|❌ não| CheckErrors{"len(missingVars) > 0?"}

    CheckErrors -->|✅ sim| ReturnMissing["❌ error 'missing required variables: %v'"]
    CheckErrors -->|❌ não| CheckEmpty{"len(emptyVars) > 0?"}
    CheckEmpty -->|✅ sim| ReturnEmpty["❌ error 'empty required variables: %v'"]
    CheckEmpty -->|❌ não| ReturnOk["✅ return nil"]

    ReturnMissing --> End(["🔵 FIM"])
    ReturnEmpty --> End
    ReturnOk --> End
```

## Fluxograma: mergeVariables

```mermaid
flowchart TD
    Start(["🟢 mergeVariables(vars)"]) --> InitMerged["merged := make(map[string]string)"]
    InitMerged --> CopyDefault["📋 Copia r.defaultVars → merged"]
    CopyDefault --> OverrideUser["⬆️ Para cada (key, value) em vars:\n   merged[key] = value"]
    OverrideUser --> ForceDate["📅 merged[VarCurrentDate]\n   = time.Now().Format('2006-01-02')"]
    ForceDate --> ReturnMerged["✅ retorna merged"]
    ReturnMerged --> End(["🔵 FIM"])
```

## Fluxograma: sanitizeVariableValue

```mermaid
flowchart TD
    Start(["🟢 sanitizeVariableValue(value)"]) --> ReplaceCRLF["value = ReplaceAll(\\r\\n, \\n)"]
    ReplaceCRLF --> ReplaceCR["value = ReplaceAll(\\r, \\n)"]
    ReplaceCR --> Split["lines = Split(value, \\n)"]
    Split --> TrimLines["🔁 Para cada line em lines:\n   line = TrimRight(line, ' \\t')"]
    TrimLines --> Join["strings.Join(lines, '\\n')"]
    Join --> ReturnSanitized["✅ retorna string sanitizada"]
    ReturnSanitized --> End(["🔵 FIM"])
```

## Fluxograma: PreviewTemplate

```mermaid
flowchart TD
    Start(["🟢 Renderer.PreviewTemplate(template)"]) --> NilCheck{"template\n!= nil?"}
    NilCheck -->|❌ nil| ReturnNil["❌ return '', error"]
    NilCheck -->|✅ ok| InitPreview["previewVars := make(map[string]string)"]
    InitPreview --> ForRequired["🔁 Para cada var em template.RequiredVars"]
    ForRequired --> AutoCheck{"isAutoGeneratedVar(var)?"}
    AutoCheck -->|✅ sim| SkipAuto["⏭️ (será preenchido pelo merge com valor real)"]
    AutoCheck -->|❌ não| SetPreview["previewVars[var] = '[strtolower(var)]'\n   ex: '[task]', '[rules]'"]
    SetPreview --> SkipAuto --> RenderPreview["Renderer.RenderTemplate(template, previewVars)"]
    RenderPreview --> ReturnPreview["✅ retorna preview string"]
    ReturnNil --> End(["🔵 FIM"])
    ReturnPreview --> End
```

## Regras de Validação de Variáveis

| Regra | Detalhe |
|-------|---------|
| `vars == nil` | Convertido para `map[string]string{}` |
| `CURRENT_DATE` | Sempre auto-generated, nunca requerido do usuário |
| Variáveis vazias/trimmed | Consideradas erro (`empty required variables`) |
| Variáveis extras | Ignoradas silenciosamente |
| `CURRENT_DATE` override | Mesmo se o usuário fornecer um valor, é sobrescrito com a data atual |
